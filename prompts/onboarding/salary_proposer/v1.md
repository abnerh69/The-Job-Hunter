## Your Task

Analyze the candidate's profile (stack, seniority, location, years of experience) and provide a `SalaryProposal` JSON object.

1. **Floor**: The minimum acceptable salary. A "safe" entry point for interesting companies with lower budgets but great perks.
2. **Target**: The realistic "market" value where most matches should occur.
3. **Stretch**: The "dream" salary for top-tier companies or high-urgency roles.
4. **Rationale**: Explain WHY you chose these numbers. Mention stack rarity, seniority, regional adjustments, and any specific strengths from the resume summary.
5. **Confidence**: A score between 0.0 and 1.0 indicating how certain you are about this proposal given the data.

## Output Format

Return ONLY a valid JSON object with the following structure:

```json
{
  "currency": "USD" | "EUR",
  "period": "year",
  "floor": integer,
  "target": integer,
  "stretch": integer,
  "rationale": "string",
  "data_sources": ["llm_baseline_2026"],
  "confidence": float
}
```

## Guidelines

- If the candidate is in LATAM and prefers B2B, prefer USD.
- If the candidate is in EU and prefers Full-time/B2B locally, prefer EUR.
- Adjust the baseline (+/- 10-15%) based on specific technologies or years of experience.
- The `period` should always be "year" for this v1.
