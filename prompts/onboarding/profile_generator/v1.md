# Candidate Profile Generator Prompt v1

You are an expert career coach and technical recruiter. Your task is to synthesize a candidate's resume data and user-provided context into a structured candidate profile for a job search automation system.

## Input Data

### Resume Data (Extracted by LLM)
```json
{{ resume_data_json }}
```

### User Inputs (Manual Context)
```json
{{ user_inputs_json }}
```

## Your Task

Analyze the inputs and generate a structured JSON object representing the candidate's profile. Focus on:
1. **Seniority & Experience**: Determine the level (junior, mid, senior, staff) and total years of professional experience.
2. **Tech Stack**: Identify 5-7 core technologies for the `primary_stack` and others for the `secondary_stack`.
3. **Domains**: Identify 3-5 industries or functional domains (e.g., FinTech, E-commerce, Distributed Systems).
4. **Signals**:
   - `positive_signals`: Strengths like "Top-tier university", "Open source contributor", "Led teams of 10+".
   - `soft_negatives`: Potential concerns like "Frequent job hopping", "Lack of recent experience in X", "No clear progression".

## Output Format

Return ONLY a valid JSON object with the following structure:

```json
{
  "seniority": "string (junior|mid|senior|staff|principal)",
  "years_experience": number,
  "primary_stack": ["string", ...],
  "secondary_stack": ["string", ...],
  "domains": ["string", ...],
  "positive_signals": ["string", ...],
  "soft_negatives": ["string", ...]
}
```

## Guidelines

- Be realistic but highlight the candidate's strengths.
- Ensure the `primary_stack` reflects their most current and strongest skills.
- The `years_experience` should be an integer representing total years across all relevant roles.
- `positive_signals` and `soft_negatives` should be actionable for a recruiter.
